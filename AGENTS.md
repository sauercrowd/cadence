# Frontend design

- Prioritize clarity and a clean, compact, precise interface inspired by Linear.
- Keep padding and gaps small. Default to 4–8 px within controls and 12–16 px for panel padding; use larger spacing only when it improves readability.
- Use restrained corner radii: 3–4 px for controls and panels, at most 6 px for dialogs. Preserve circles for status indicators and avatars where appropriate.
- Avoid chunky controls, oversized cards, decorative containers, slogans, and redundant explanatory copy. Labels should describe actions or state directly.
- Focus the primary text field when opening a creation dialog, after the dialog is shown. Keep keyboard operation and visible focus indicators intact.
- Inspect meaningful UI changes in the browser at desktop and compact widths. Check spacing, overflow, and keyboard interactions, not only compilation.
